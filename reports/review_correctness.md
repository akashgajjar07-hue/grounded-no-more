**Formulas.**
- Palm/EBO: A(S) = P(X ≤ S−1); EBO = μ − S + Σ_{x<S}(S−x)p(x); wait = EBO/λ. The JS mirror is identical (`lgamma(k)` there is log k!, consistent). `test_floatcalc_mirror` passes.
- NB parameters: p = m/v, n = mp/(1−p) (correct for scipy). ROP = smallest s with P(LTD ≤ s) ≥ service, consistent with the engine trigger `IP ≤ s` (`engine.py:381`). EOQ is Harris–Wilson.
- Croston/SBA: updates only on demand periods; SBA factor 1 − α/2. TSB: probability updated every period. MASE uses in-sample naive scale and returns NaN on a zero scale. PIS = ΣΣ(f − y) (Wallström & Segerstedt).
- Paired t-CIs are standard.
- Annualisation: KPI window 104–155 inclusive = 52 weeks, `ann = 1`.
- Total cost = holding + repair + logistics + expedite + AOG penalty (`KPI_COST_KEYS`). Capital is time-averaged owned value and is not added. The expedite premium goes to `c_exp` and the purchase value to `c_buy`, which is excluded, so nothing is double counted. TAT-acceleration cost = (1 − m)·days·400 goes into repair cost.
- Frontier: h* = 0.2·1e6/21,238 = 9.417 h per AED 1M. The I125 → B175 segment (1.405) is below h*, so I125 is selected, which matches the rule. The lower hull (monotone chain) is correct. I recomputed the `nondominated` flags for all 23 holdout and selection points: 0 mismatches.
